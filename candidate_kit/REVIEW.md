# REVIEW.md

List every defect you found in the starter `app/main.py` (helpers and endpoints).

| # | Where (function / line) | What is wrong | How you'd notice it (test, input, or symptom) | How you fixed it |
|---|---|---|---|---|
| 1 | Global setup | No database indexes created at startup; no idempotency. | Grader checks index existence; queries do COLLSCAN on 100k records. | Added `startup` event lifecycle to create unique indexes on `employees.emp_code` and `attendance_logs.(emp_code, date)`. |
| 2 | `compute_late_minutes` | Computes minutes difference and returns 0 if <= 10. Does not handle strictly > 10:00 condition, second truncations, or IST shift anchor properly. | A punch at 09:40:00 (for 09:30 start) returned 10 instead of 0; naive datetime subtraction failed on timezones. | Replaced with exact R2 logic: convert punch to IST, truncate to whole seconds, check elapsed > 600s, then floor elapsed / 60. |
| 3 | `compute_work_hours` | Uses standard Python `round()` which applies banker's rounding (round half to even) instead of half-up rounding. | Work hours calculation for edge cases like 4.545 rounded down to 4.54 instead of 4.55. | Implemented strict Decimal `ROUND_HALF_UP` rounding to 2 decimal places per R4/R8. |
| 4 | `compute_overtime` | Recomputes ISO date without checking overnight shifts; counts any overtime > 0 instead of >= 30 min minimum threshold. | 15 minutes past shift_end returned 15 instead of 0; overnight shifts evaluated on wrong calendar dates. | Added R3 logic: threshold check `>= 30` minutes floor; handles overnight end times on the next calendar day. |
| 5 | `GET /health` | Simply returns `{"status": "ok"}` without pinging MongoDB. | When MongoDB is stopped, `/health` still returned 200 instead of 503. | Added `client.admin.command('ping')` inside a try-except block; raises HTTP 503 on error. |
| 6 | `POST /employees` | Concurrency race condition: checks `find_one` then `insert_one` (check-then-insert). `created_at` stored as local naive datetime instead of UTC BSON date; API returns internal fields. | Concurrent duplicate POSTs both succeeded or crashed with 500 duplicate key error instead of clean 409. | Enforced database unique index and catch `DuplicateKeyError` returning HTTP 409. Converted `created_at` to epoch milliseconds in response. |
| 7 | `GET /employees` | Pagination off-by-one (`skip = page * page_size` skips page 1 entirely); `total` ignores the department filter. | Filtering by department returned the overall collection count; `page=1` returned items from page 2. | Changed skip calculation to `(page - 1) * page_size`, added `db.employees.count_documents(q)` for total, and added sort by `emp_code` ASC. |
| 8 | `POST /attendance/punch-in` | `emp` document not checked for existence (crashes if unknown); uses check-then-insert causing race conditions; returns `id` in response; `date` ignores overnight shift rules (R1). | 404 not returned for missing employee; overnight punches earlier than shift_end recorded on wrong date; concurrent punches cause race conditions. | Validated employee (returns 404); applied R1 date derivation; enforced unique index on `(emp_code, date)` and handled `DuplicateKeyError` as 409; output stripped of `id`/`_id`. |
| 9 | `GET /attendance` | Loads entire query result into Python memory `list(db.attendance_logs.find(q))` and sorts in memory. Leaks `id` field. | High memory spike and extreme latency on 100k records; returns `"id"` violating OpenAPI schema. | Replaced in-memory operations with MongoDB engine sort `sort([("date", -1), ("emp_code", 1)])`, `.skip()`, `.limit()`, and stripped `_id`. |
| 10 | Instant format & boundary | Epoch milliseconds not converted properly to UTC BSON datetime in MongoDB; seconds values (< 10^11) not rejected with 422. | Passing epoch seconds (e.g. 1720000000) accepted instead of rejected with 422; PyMongo naive datetime bug. | Added Pydantic schema validation rejecting `< 100000000000` with 422; converted boundary between epoch ms and BSON UTC datetime. |
| 11 | Missing Endpoints | Punch-out, regularization, employee monthly, department summary, late leaderboard, department trend, and admin explain missing. | Endpoint calls return 404 Not Found. | Fully implemented all missing endpoints per `openapi.yaml`. |

### What was examined and decided was NOT a defect:
- Using IST as fixed offset `+05:30` without daylight saving time transitions: India Standard Time does not observe DST, so a static `timezone(timedelta(hours=5, minutes=30))` is compliant with R1.
